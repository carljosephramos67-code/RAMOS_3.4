# Non-Linear Data Structure (Assessment 3.3) - RAMOS

Python (PyCharm) program. Each structure is in its own file:

- `binary_tree.py` - Binary Tree with DFS and BFS (runnable by itself)
- `graph.py` - Graph with DFS and BFS (runnable by itself)
- `main.py` - asks for your last name, then runs both

Run: open the folder in PyCharm and run `main.py` (or run either structure file alone).

Expected output:
- Binary Tree DFS: R - A - O - S - M
- Binary Tree BFS: R - A - M - O - S
- Graph DFS: R - A - O - S - M
- Graph BFS: R - A - M - O - S
